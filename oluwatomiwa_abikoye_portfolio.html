01 / 03

PaceCore

Run Club Management SaaS Platform

.NET 9 Blazor WASM Hangfire Paystack API Clean Architecture
Live deployment →
Problem
Membership tracking, payment validation, and club statistics are managed manually — creating administrative overhead that scales poorly as clubs grow.
Architecture
Built on Clean Architecture with strict one-way dependency flow. A domain-level membership state machine enforces lifecycle transitions. Hangfire handles automated billing snapshots, expiry processing, and statistics recalculation as background jobs.
Engineering Decision
Payment validation is enforced at the domain entity level — not just the API boundary. This prevents invalid membership states regardless of how the system is accessed, ensuring financial logic is never bypassable.
Lesson Learned
State machines are underused in SaaS. Modelling membership lifecycle explicitly eliminated an entire class of bugs that would otherwise surface as edge-case UI errors.
02 / 03

Monivise

Personal Financial Decision Engine

.NET 9 Blazor WebAssembly Fluxor JWT Auth ASP.NET Core
Screenshots coming soon
Problem
Personal finance tools tell you what you spent. They rarely tell you what you can safely spend right now, in real time, with confidence. Most lack the decision-layer that bridges data and action.
Architecture
A real-time financial decision engine built on Clean Architecture. Immutable calculation rules — including a SafeToSpend formula — are isolated in the domain layer. A JWT-authenticated ASP.NET Core 9 Web API serves a Blazor WebAssembly frontend with Fluxor for predictable state management.
Engineering Decision
Financial calculation rules are immutable and domain-isolated. They cannot be overridden by application-layer concerns. This mirrors how accounting systems handle double-entry bookkeeping — correctness by construction.
Lesson Learned
Fluxor (Redux pattern for Blazor) adds meaningful complexity. The payoff is only worth it when state genuinely needs to be shared across many components — something worth validating earlier in the design process.
